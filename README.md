# Northbound

A polished Android compass built with Jetpack Compose. The dial follows the device's rotation-vector sensor and displays a magnetic heading in degrees and cardinal directions. It needs no permissions or network access.

## Build

Open this folder in Android Studio with Android SDK 35 installed, then run the `app` configuration on a device or emulator with a rotation-vector sensor. The project uses JDK 17 for Gradle builds.

Alternatively, from this folder run `gradle :app:assembleDebug` if Gradle is installed.

The generated APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

## GitHub Actions builds and releases

The workflow in `.github/workflows/android.yml` builds the debug APK on branch pushes, pull requests, and tag pushes. You can download it from the workflow run's artifacts. Pushing any tag also creates or updates a GitHub Release and attaches the APK as `Northbound-<tag>.apk`.

To publish a release, push a tag from the project repository:

```bash
git tag v1.0.0
git push origin v1.0.0
```

The attached APK is a debug build, signed with the temporary debug key generated by Android Gradle Plugin. It is suitable for testing and direct installation, but is not a stable signing identity for app updates or a Play Store release.
